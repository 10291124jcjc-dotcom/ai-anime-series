# 03 提示词怎么拼

提示词由 `scripts/make_prompts.py` 按 `series.json` + `episode.json` 拼出来，不是一段死模板：出场角色多一个，@图 就多一个；镜头少几格，宫格就变小。

## 参考图编号

顺序固定：这集出场的角色（按 `cast` 顺序）→ 有设定图的群体角色 → 场景设定图 → 故事板（永远最后）。

| 这集出场 | 编号 |
| --- | --- |
| 汤圆、油条 | @图1 汤圆、@图2 油条、@图3 故事板 |
| 汤圆、油条、鸽子老大，公园有场景图 | @图1 汤圆、@图2 油条、@图3 鸽子老大、@图4 公园、@图5 故事板 |

- 没出场的角色不传、不写
- 没有设定图的群体角色只用文字写（「鸽子帮：一群灰色城市鸽子……」）
- 超过参考图上限（默认 9，第三方说法，以即梦当前限制为准，`JIMENG_MAX_REFS` 可改）会报错：把配角设定图用 `grid.py grid` 拼成一张

## 故事板提示词

```
生成 16:9 九宫格（3 行 3 列）动画分镜素描草图。要求：黑白铅笔素描、画面干净不杂乱、不要复杂背景、
无多余画面、无文字，每格左上角标镜头序号。角色外形参考：图 1 是汤圆，图 2 是油条。
全部 9 格在同一个城市公园，同一个午后。
镜头 1：……
……
镜头 9：……
```

**一定要黑白素描**：故事板只用来定构图、动作、景别。画成彩色成品，Seedance 会照抄画面，甚至把宫格直接拼进视频。

## 视频提示词

五块，顺序固定：

1. 「根据故事板 @图N 生成分镜视频，仅参考其镜头设计、动作节奏、景别和运镜，禁止直接拼接故事板图片。」
2. 每个出场角色一行「@图k 是谁，外形必须和参考图完全一致：（look）」
3. 风格（系列统一）+ 没有台词 + 地点和时间
4. 连贯要求：每个镜头的开头接住上一个镜头结尾的动作；奔跑方向不乱换；同一个跟拍中间不换机位
5. 每个镜头两行：「镜头 i｜a-b s：画面」「音效：……」，最后「画面里不要出现任何文字、字幕、商标」

镜头条数和故事板格数一一对应；秒数首尾相接，加起来等于这段时长。

## 运镜和动作写法

- 运镜词：缓慢推近、缓慢上摇、侧面跟拍、低角度仰拍、俯拍、拉远、定格
- 动作写「谁 + 怎么动 + 结果」：「油条把身体拉得超长横跨水沟当桥，汤圆从它背上滚过去」
- 夸张动作直接写形变：「拉成一张弹弓」「越拉越长」「像保龄球一样」
- 一个镜头只写一个主动作，背景里的反派可以带一句（「后面追来的鸽子撞成一团」）

## 音效写法

每个镜头一行，写 2–3 个：环境声 + 动作声 + 配乐变化。卡通音效最出效果：弹簧音、长号「哇哇哇」、定格重音、配乐急停。
