# 04 即梦画布里怎么操作

全部在即梦（海外用 Dreamina）的**画布**里做：每张图是一个节点，框选几个节点再生成，就是把它们当参考图。

## 第一次：设定图

1. 新建画布 → 图片生成
2. 复制 `SERIES/prompts/设定_XX.txt` 分隔线以下的整段，比例 1:1 或 16:9，一次出 4 张
3. 挑一张，下载，存进 `SERIES/refs/`（文件名和 `series.json` 里的 `ref` 一致），发给 Claude 检查
4. 每个角色一个节点，留在画布里，以后每集都框选它们

## 每集：故事板

1. 框选这集出场角色的设定图节点（有场景图也框上）
2. 图片生成，复制 `epNN/prompts/1_故事板.txt` 分隔线以下的整段
3. 出 4 张，挑格数对、编号对、每格动作对的一张
4. 下载存成 `epNN/故事板.png`，故事板节点留在画布里

某一格不对：`make_prompts.py SERIES epNN panel 6` 拿单格提示词，只重出那一格；`grid.py split` 把原故事板切开，换掉那一格，`grid.py grid` 拼回去，再拖回画布。

## 每集：视频

1. 框选：角色设定图 + 场景图 + 故事板（提示词第一行写了要框哪几个、顺序是什么）
2. 视频生成 → **Seedance 2.5** → **全能参考**
3. 比例和时长照提示词第一行选（15 / 30 秒），**清晰度先选 480p**
4. 复制 `epNN/prompts/2_视频.txt` 分隔线以下的整段
5. 生成后下载放进 `epNN/clips/`，让 Claude 跑 `review_clip.py` 检查
6. 满意了再用即梦的超清，不满意只改出问题的镜头描述重出

1 分钟的有两份：`2_视频_A.txt`、`2_视频_B.txt`，两段各用自己的故事板，生成后 `compile.py concat` 拼起来。

## 省钱

- 480p 抽卡，满意了再超清
- 故事板先出对，再出视频：故事板错了视频一定错
- 只有一两个镜头不对时，用 `patch` 补拍那几格，不要整集重来
