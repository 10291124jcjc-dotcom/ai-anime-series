# 01 角色：怎么立 IP

单元剧靠角色撑。观众记住的是「那只圆仓鼠和那条长腊肠狗」，不是哪一集的故事。

## 规矩

1. **剪影差别大**：一圆一长、一高一矮、一胖一瘦。缩成小黑影也能认出谁是谁，模型也不容易把两个角色混成一个。
2. **主色不撞**：每人一个主色（白 / 金棕 / 红），配饰用对比色（油条的红围巾）。
3. **每人一个招牌能力**：从身体特点长出来。油条身子长 → 能当桥、当弹弓、当绳子；汤圆圆 → 能滚、能当保龄球、能卡进洞里。剧本的笑点主要从这里来，所以要选能「变出很多用法」的特点。
4. **性格一句话**：又馋又怂、憨又护食。有了性格，同一个能力用出来才有戏。
5. **名字好记**：两三个字，最好是吃的、东西的名字，比如汤圆、油条、辣条、麻薯。
6. **反派**：一群一样的角色（鸽子帮、鬣狗群）算一个「群体角色」，可以有一只特别的（特别胖、戴墨镜）。
7. **只做原创**：不用真人，不照搬现有动漫、品牌吉祥物、别人账号的角色。

## series.json 里怎么写

```json
{
  "id": "youtiao",
  "name": "油条",
  "ref": "refs/油条.png",
  "look": "身体特别长的腊肠犬，金棕色短毛，四条小短腿，长长的耷拉耳朵，大黑鼻头，眼睛有点斗鸡眼，脖子上系一条红色小围巾",
  "ability": "身子长，能拉长当桥、当弹弓、当绳子",
  "personality": "又馋又怂",
  "expressions": ["开心", "惊吓", "生气", "流口水", "得意", "无奈"],
  "poses": ["趴着", "身体拉长奔跑", "叼东西", "身体弯成拱桥"]
}
```

- `look` 写死外形：物种、体型、颜色、眼睛、标志性配饰。每集的视频提示词都会原样带上这段。
- `poses` 里放一两个和招牌能力有关的姿势（「身体弯成拱桥」），设定图里先画出来，视频里更容易做对。

## 设定图

`python scripts/make_prompts.py SERIES sheets` 给每个角色一份提示词：三视图 + 表情 + 动作 + 剪影，纯白底。在即梦画布里出 4 张挑 1 张。

挑的时候看：

- 三视图前后长得一样（耳朵、花纹、配饰位置一致）
- 没有多手多脚、没有融在一起的肢体
- 和 `look` 对得上（颜色、配饰）
- 图上的字乱码没关系（视频提示词会写「禁止出现文字」），但角色名写错了可以重出

比例用 1:1 或 16:9 都行。宽高比超出 0.4–2.5 的图（比如车的四视图横排）即梦传不上去，用 `grid.py rewrap` 改排两行。

常用场景（公园、窝）也可以出一张场景设定图，写进 `scenes` 的 `ref`，每集画面会更稳；不出也行，脚本会用文字描述场景。
